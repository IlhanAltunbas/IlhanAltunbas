### Featured projects

[DusAssistant](https://github.com/IlhanAltunbas/DusAssistant) - Bilingual RAG study assistant for the Turkish dental specialty exam, running in production on Azure. Kotlin Multiplatform client; FastAPI backend on Azure Container Apps with Azure OpenAI and Azure AI Search, behind provider-agnostic LLM and vector-store interfaces. Tested in CI with GitHub Actions and measured on a 28-question evaluation set with an LLM judge: an agent mode built with LangGraph raised fully correct answers from 42% to 72% on that set with comparable faithfulness to the sources. Latency profiling roughly halved generation time, at zero fixed infrastructure cost.

[T88Controller](https://github.com/IlhanAltunbas/T88Controller) - Kotlin Multiplatform app for Android and iOS that controls professional audio hardware over the network, built in two months during an internship at MrHolo: asynchronous TCP sockets for bidirectional sync, a custom protocol parser for hexadecimal frames with bitwise masking, and a shared Compose Multiplatform UI.

[DivvyDrive](https://github.com/IlhanAltunbas/DivvyDrive) and [File-Reader](https://github.com/IlhanAltunbas/File-Reader) - Android cloud file-management apps: 16 REST endpoints with ticket-based authorization, MVVM with Hilt and Coroutines, and offline metadata extraction with Apache POI and PDFBox.
